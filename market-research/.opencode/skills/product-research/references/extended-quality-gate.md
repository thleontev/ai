# Расширенный quality gate

Прочитай после блокирующего quality gate из `SKILL.md` при подготовке полного отчёта. Каждый применимый пункт обязателен; явно отмечай недоступные доказательства вместо формальной галочки.

- [ ] схема SQLite применена до вызовов источников либо точная ошибка указана в разделе «История исследования»;
- [ ] до сбора создан паспорт запуска; в нём нет секретов и отражены доступные MCP, лимиты и ограничения;
- [ ] до аналитических вызовов выбран режим географии; запрошенный охват и фактическое покрытие каждого источника видны в разделе «Цель и условия исследования», паспорте и разделе «Географическое покрытие»;
- [ ] перед Авито выполнены `avito_session_open` и `avito_session_status` с `authorized: true`; ID локации получен через `avito_location_search`, а не перенесён из Яндекса;
- [ ] при доступных category-метриках Авито собрана только релевантная ветка `верхняя категория → … → целевая категория` либо явно указано, что ID/родительские узлы недоступны; сводка несвязанных «всех категорий» не выдана за структуру товара;
- [ ] для каждого использованного узла категории сохранены ID, родительский ID (если доступен), глубина, город, период, показатели и `evidence_ref` в `market_category_snapshots` либо в «Исходных данных» при недоступном SQLite;
- [ ] при доступном SQLite существует запись `research_runs`;
- [ ] у каждой метрики есть дата, период, регион и уровень данных;
- [ ] у каждого использованного MCP-ответа есть `evidence_ref`; для Авито это возвращённый сервером `archived`;
- [ ] прошлые значения сопоставлены только при совпадении запроса, источника, региона, метрики и периода;
- [ ] семантика включает синонимы, язык задачи, модификации и нерелевантные термины, где это применимо;
- [ ] пересекающиеся фразы Wordstat не сложены как размер рынка;
- [ ] данные `query`, `cluster`, `category`, `listing` и `region` не спутаны;
- [ ] Stage 0 классифицировал путь покупки;
- [ ] `channel_mismatch` не назван отсутствием рынка;
- [ ] B2B / закупочная ветка использует специальный workflow и не придумывает размер рынка или готовность платить;
- [ ] discovery-слой в РФ использует Search API (Яндекс) и сохраняет «Журнал поисковых запросов»; браузер открывает только конкретные публичные страницы;
- [ ] первые поисковые запросы — точные коммерческие/профессиональные фразы Wordstat;
- [ ] для отложенного поиска явно сообщено об ожидании ≥5 минут и результаты собраны до истечения 12 часов;
- [ ] для локального B2C, заказных товаров и услуг семантика и сопоставление сигналов выделяют повод покупки, если он виден в запросах или публичных предложениях;
- [ ] для локального B2C проверены доступные публичные карты, каталоги услуг или классифайды, либо ограничение явно указано;
- [ ] если Stage 0 установил `social_channel_relevant: yes`, публичные социальные каналы проверены через Яндекс и «Журнал проверки социальных площадок», либо ограничение явно описано;
- [ ] социальная витрина, активность и показатели вовлечения не выданы за спрос, продажи или размер рынка;
- [ ] при использовании внешнего Telegram-каталога или аналитического сервиса указаны сервис, дата, метод и ограничение; его оценка не выдана за полный охват или продажи;
- [ ] бриф платного теста подготовлен только по явному запросу пользователя и не привёл к созданию рекламы, пикселей или расходам;
- [ ] соблюдены ограничения страниц на запрос и на исследование либо записано основание их расширения;
- [ ] у каждого веб-факта есть URL, дата доступа, тип источника и уровень данных;
- [ ] сниппеты, заявления продавца, отдельные цены и отзывы не выданы за статистику рынка;
- [ ] каждый созданный график воспроизводим из `charts-spec.json`, содержит источник, регион, период, уровень данных и `evidence_ref`;
- [ ] Wordstat и Авито не объединены на одной числовой шкале; диапазон цен показан только для однородной выборки минимум из пяти предложений;
- [ ] при двух и более сопоставимых category-строках есть таблица «Предложение и отклик» и `market_profile` с раздельными панелями; при единственной строке причина отсутствия графика указана;
- [ ] каждая страница PDF с графиком визуально проверена по PNG: подписи, шкалы, легенды, диапазоны и footer не обрезаны и не перекрывают данные; таблицы рядом с графиками распознаны как таблицы;
- [ ] Markdown-отчёт собран в одноимённый PDF через `md2pdf`; HTML не содержит предупреждений `WARN table separator`, `WARN block boundary` или `WARN nested list`, выбранные фразы в `pdf-check/_check.txt` найдены, PDF и PNG-страницы ненулевые;
- [ ] вложенные списки в PDF сохраняют уровни и визуальный отступ; для каждого уровня в Markdown использовано ровно 4 пробела;
- [ ] при наличии SVG-графиков в PDF проверены векторные drawings, а в разделе «PDF-версия» указан путь к PDF и итог проверки;
- [ ] CAPTCHA, антибот, аккаунт или платный доступ не обходились;
- [ ] для приоритетного сегмента есть систематическая выборка конкурентов либо явно указано ограничение;
- [ ] минимум, медиана и максимум цены рассчитаны только для сопоставимой группы не менее пяти предложений;
- [ ] контакты и просмотры названы интенсивностью отклика, а не доказанным дефицитом;
- [ ] географический лидер назван только среди проверенных регионов;
- [ ] Москва, текущая локация профиля Авито или иной случайный город не использованы как заместитель России; городские показатели Авито не агрегированы в общероссийские сумму, среднюю или статус спроса;
- [ ] при `national_with_city_sample` перечислены города, критерий их выбора и ограничение «среди проверенных городов»; при `national_sources_only` Авито не назван подтверждением общероссийского вывода;
- [ ] гипотезы разделяют факт, интерпретацию и неопределённость;
- [ ] тест на площадке не использует одновременные дубли объявлений и меняет один фактор за раз;
- [ ] присутствуют «Исходные данные», «История исследования», итоговый статус и следующий практический тест.

## Короткие анти-паттерны

Не используй следующие формулировки без прямо указанного метода и источника:

- «рынок составляет … ₽»;
- «ниша свободна» или «конкуренции нет»;
- «спрос растёт» без периода и сопоставимой базы;
- «спрос превышает предложение» только по контактам, просмотрам или широкой категории;
- «никому не нужен» по отсутствию сигнала в одном канале;
- «средняя цена» по одной карточке или несопоставимым товарам;
- «готовы платить» по заявлению продавца или единичному отзыву;
- «лидер региона / России» без явно описанной выборки;
- «GO на производство» без проверки реальной покупки, экономики и требований соответствия.
