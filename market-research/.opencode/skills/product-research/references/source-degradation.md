# Матрица деградации источников

Прочитай этот файл, когда любой нужный источник недоступен, заблокирован или возвращает неполные данные. Укажи действующую строку в ограничениях отчёта и не превышай разрешённый уровень вывода.

| Wordstat | Авито Аналитика | Web validation (Search API / Playwright) | Допустимый вывод | Обязательный статус / действие |
|---|---|---|---|---|
| доступен | доступна | доступна | Полная B2C-триангуляция; всё равно указывай уровень каждой метрики. | Обычное продолжение. |
| доступен | недоступна | доступна | Только поисковый интерес, язык рынка, публичные предложения и каналы. Не заявляй торговый спрос, баланс предложения, региональный спрос или дефицит. | `TEST` или `HOLD`. |
| недоступен | доступна | доступна | Только сигналы query/listing Авито и карта публичных предложений. Не обобщай на внешний российский спрос или сезонность. | `TEST` или `HOLD`. |
| доступен | доступна | недоступна | Предварительный анализ Wordstat + Авито. Не заявляй проверенный ценовой диапазон веба, выборку конкурентов или канал покупки. | `HOLD`, если пользователь не предоставил публичные доказательства. |
| недоступен | недоступна | доступна | Только разведочная веб-карта. Не выдавай вердикт рынку, его размеру или спросу/предложению. | `HOLD`; назови недостающие измерения. |
| недоступен | недоступна | недоступна | Нет пригодных данных для исследования. | Остановись и запроси решение пользователя. |

Web validation считается доступной, если работает Search API (`yandex-analytics` MCP: `yandex_search_sync` / `yandex_search_deferred_*`) либо Playwright может открывать конкретные публичные страницы. Discovery-слой по умолчанию — Search API; браузер — только для открытия найденных страниц.

Дополнительные правила:

- Если SQLite недоступен, текущие находки источников остаются пригодными, но укажи «История исследования: недоступна»; не делай выводов о времени.
- Если Search API недоступен (не активирован в Yandex Cloud, нет ключа с скоупом `yc.search-api.execute` или ошибки авторизации), не подменяй его Google. Зафиксируй блокировку. Допустимо проверить предоставленные пользователем или ранее найденные публичные URL через Playwright, но назови discovery-слой неполным. Снизь плотность запросов и сделай паузу; при постоянном профиле браузера однократное ручное решение SmartCaptcha даёт доверенную cookie на время.
- При блок-странице Авито в Playwright («Доступ ограничен: проблема с IP» или капча) не считай её данными и не подменяй объявления сниппетами поисковой выдачи. Сделай паузу 30–60 секунд и до двух повторов; затем используй строку матрицы для недоступного веба и явно укажи блокировку в ограничениях отчёта. Легальное снятие блока: постоянный профиль браузера (без `--isolated`), однократное ручное решение капчи, пауза до «остывания» IP.
- При блокировке **`avito-analytics` MCP** не делай повторов `avito_market` или `avito_wordstat`: сервер сам выставляет `blocked_until` на 24 часа. Зафиксируй `block_reason`, `blocked_until` и переходи к соответствующей строке матрицы. Повторить можно только новый `avito_session_status` после истечения паузы.
- Отложенный поиск Search API: отправь батч в начале web validation, собери результаты не раньше чем через 5 минут и не позже чем через 12 часов; агент обязан явно сообщить пользователю об этом ожидании. Не перезапускай сервер MCP между отправкой и сбором — реестр отложенных запросов живёт в памяти процесса.
- При временном сбое источника допустимы не более двух повторов. Затем используй строку матрицы; не зацикливайся.
