# Авито — раздел «Аналитика спроса»: устройство и API

Документация по результатам исследования (18.08.2026, авторизованная сессия Playwright).

## 1. Разделы (табы)

Раздел «Аналитика спроса» доступен в личном кабинете по адресу `/analytics`.
Состоит из двух табов, все параметры пробрасываются в URL:

| Таб | URL | Назначение |
|---|---|---|
| «Спрос в категориях» | `/analytics` | Таблица категорий/подкатегорий: Продавцы, Объявления, Просмотры, Контакты, уровень спроса |
| «Поисковые запросы» | `/analytics/wordstat` | Частота поисковых запросов по дням, сравнение нескольких фраз |

Пример URL с параметрами: `/analytics?categoryId=7&sortingDirection=desc&sortingField=demand`

## 2. Таб «Спрос в категориях»

- Таблица с колонками: **Название, Продавцы, Объявления, Просмотры, Контакты** + уровень спроса (1–3).
- Клик по строке категории → детализация по подкатегориям (глубина — любая по дереву категорий).
- Период: **день** (вчера) или **месяц** (прошлый месяц).
- Фильтры: регион, округ, метро, цена, тип продавца (доступность зависит от категории).
- Сортировка: по любому полю, asc/desc.
- Ограничения: категории с <5 продавцами скрыты (`minSellersCount: 5`), часть полей недоступна (`hiddenFields`, `forbiddenNodes`).

### Показатели строки
- `countSellers` — число продавцов за период
- `countItems` — число объявлений
- `views` — просмотры
- `contacts` — контакты (запросы контактов по объявлениям)
- `demand.value` — уровень спроса 1–3
- `demand.estimate` — оценочный показатель спроса

### Дополнительно при детализации (`summary`)
- `parentNodeName` — родительский узел
- `categoryRateByItems` — доля категории по объявлениям
- `viewsPerItem` — просмотров на объявление
- `viewsToContactConversion` — конверсия просмотров в контакты (%)

## 3. Таб «Поисковые запросы» (wordstat)

- Ввод одной или нескольких фраз (до N фраз, сравнение на одном графике).
- Период: **7 дней** или **30 дней** (по дням).
- Фильтры: регион (населённый пункт), категория (автокомплит по дереву).
- Тумблер «Точный поиск» (`strictMode`).
- Ответ — поседневные counts по каждой фразе.

## 4. API-эндпоинты

Все эндпоинты — `POST`, JSON, тот же origin `https://www.avito.ru`,
авторизация через cookies сессии (антибот-флаги `cfidsw-avito`, `__zzatw-avito` и др.).
Отдельного заголовка Authorization нет.

### 4.1. Спрос в категориях

```
POST /web/1/sellers/analytics/market
```

Тело запроса:

```json
{
  "filters": {
    "nodeId": null,
    "locationIds": [660630],
    "districtIds": [],
    "metroIds": []
  },
  "dynamicFilters": {},
  "group": "month",
  "order": "name",
  "direction": "asc",
  "splitBy": "category"
}
```

Параметры:

| Поле | Значения | Назначение |
|---|---|---|
| `filters.nodeId` | `null` = все категории; `7` = Электроника и т.д. | Узел дерева категорий |
| `filters.locationIds` | `[660630]` = Сургут | Регион(ы) |
| `filters.districtIds` / `metroIds` | `[]` | Округ / метро |
| `dynamicFilters` | `{}` | Цена, тип продавца и пр. |
| `group` | `day` \| `month` | Период агрегации |
| `order` | `name`, `demand`, `contacts`, `views`, … | Поле сортировки |
| `direction` | `asc` \| `desc` | Направление сортировки |
| `splitBy` | `category` (и `district`, `metro`, `price` — при доступности) | Разрез данных |

Ответ:

```json
{
  "breadcrumbs": [],
  "config": {
    "filtersByDistrictId": false,
    "filtersByMetroId": false,
    "filtersByPrice": false,
    "filtersByRoadId": false,
    "filtersBySellerType": false,
    "filtersBySplitBy": false,
    "group": { "options": { "day": "За 17 августа", "month": "За июль" } },
    "hiddenFields": [],
    "isForbidden": false,
    "minSellersCount": 5,
    "splitBy": { "options": { "category": "По подкатегориям" } }
  },
  "filtersScheme": [],
  "forbiddenNodes": [],
  "nodes": [
    {
      "contacts": 45893,
      "countItems": 36820,
      "countSellers": 12078,
      "demand": { "estimate": 1.25, "value": 2 },
      "nodeId": 7,
      "nodeName": "Электроника",
      "views": 1411414
    }
  ],
  "summary": { ... }
}
```

### 4.2. Поисковые запросы (wordstat)

```
POST /web/1/sellers/analytics/wordstat
```

Тело запроса:

```json
{
  "queries": ["телефон"],
  "filters": {
    "duration": "week",
    "locationId": null,
    "categoryId": 7
  },
  "strictMode": false
}
```

Параметры:

| Поле | Значения | Назначение |
|---|---|---|
| `queries` | `["фраза1", "фраза2", …]` | Список фраз (массив — по одному count на фразу на дату) |
| `filters.duration` | `week` \| `month` | 7 или 30 дней |
| `filters.locationId` | `null` или id региона | Регион |
| `filters.categoryId` | `null` или id категории | Категория |
| `strictMode` | `true` \| `false` | Точный поиск (тумблер) |

Ответ:

```json
{
  "periodData": [
    { "counts": [19640], "date": "2026-08-11" },
    { "counts": [19366], "date": "2026-08-12" }
  ]
}
```

`counts` — массив по числу фраз в `queries` (для 2 фраз — `[n1, n2]` на каждую дату).
Сумма counts по датам = «Всего запросов» на странице.

### 4.3. Вспомогательные

```
POST /web/1/sellers/analytics/market/location
```
Тело: `{}` → Ответ: `{"id": 660630, "name": "Сургут"}` (текущий регион).

```
GET /web/1/slocations?locationId=621540&limit=10&q=Москва
```
Публичный suggest локаций (тот же, что у селектора региона на главной): не требует
авторизации, бюджет аналитики не тратит. Ответ: `result.locations[]` — `{id, names: {"1": ...},
parent?}`. Используется инструментом `avito_location_search`; результаты кэшируются в
`data/locations-cache.json` (30 дней).

```
POST /web/1/sellers/analytics/market/microcat/suggest
```
Тело: `{"query": "Электроника"}` → подсказки микрокатегорий для `dynamicFilters`.

## 5. Особенности и ограничения

- Все данные агрегированы анонимно; категории с <5 продавцами не показываются (анти-деанон).
- Часть категорий/полей скрыта (`forbiddenNodes`, `hiddenFields` в `config`).
- Данные обновляются с задержкой: «За 17 августа» = вчерашний день, «За июль» = прошлый месяц.
- Авторизация — cookies, а не токен: воспроизвести API можно только с cookies авторизованной сессии браузера.

## 6. Способы получения данных

### Вариант A (безопасный) — через браузер
Навигация по страницам + перехват ответов `page.on('response')` → JSON/CSV.
Рандомные паузы 5–15 сек. Минимальный риск бана.

### Вариант B (эффективный) — fetch из контекста страницы
`page.evaluate(() => fetch('/web/1/sellers/analytics/market', {...}))` — cookies и
антибот-заголовки подставляются автоматически, запросы выглядят как фронтенд.
При паузах 5–15 сек риск CAPTCHA/ограничений ~1–5%; при агрессивном режиме
(сотни запросов, <3 сек) — капча/временная блокировка раздела.

### Вариант C (рискованный) — внешние HTTP-запросы
curl/requests + cookies (`sx`, `cfidsw-avito` и др.) — Авито активно банит,
высокий риск 403/CAPTCHA/блокировки. Не рекомендуется.

### Вариант D — публичные данные без авторизации
`/populyarnye-zaprosy` — только топ запросов, без динамики и деталей.

### Рекомендации по лимитам (вариант B)
- паузы случайные 8–20 сек, не кратные
- серия ≤ 30–50 запросов, затем перерыв 10–30 мин
- не перебирать регионы монотонно подряд
- при появлении капчи — полная остановка на 24 ч+
- желательно отдельная «рабочая» сессия для скрипта
