# Avito Analytics MCP

Локальный stdio MCP для раздела «Аналитика спроса» Авито. Он открывает авторизованную сессию системного браузера и предоставляет AI-агенту данные спроса в категориях и поисковых запросов.

Установка, переменные окружения, ручная авторизация и ограничения описаны в [SETUP.md](SETUP.md). Сервер работает только локально: профиль браузера, cookies, состояние и архив ответов по умолчанию хранятся в `%LOCALAPPDATA%\OpenCode\avito-analytics`, а не в репозитории.

Не пытайтесь обходить CAPTCHA, 403 или 429. При блокировке сервер сам задаёт безопасный cooldown.
