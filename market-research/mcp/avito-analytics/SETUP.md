# Avito «Аналитика спроса» — настройка и установка (для пользователя)

MCP-сервер `avito-analytics` получает данные из раздела «Аналитика спроса» Авито
(спрос в категориях и частотность поисковых запросов) через авторизованную сессию браузера
и отдаёт их ИИ-агенту. Защита от блокировок: случайные паузы 8–20 сек, лимит 50 запросов
на серию, автопауза 24 ч при капче.

## 1. Что необходимо

| Требование | Детали |
|---|---|
| Node.js | ≥ 18 (проверка: `node -v`) |
| Браузер | Установленный **Chrome** или **Edge** (не нужно скачивать браузеры Playwright — сервер использует системный браузер) |
| Аккаунт Авито | Обычный аккаунт, один раз авторизоваться вручную |
| Доступ к разделу | Раздел «Аналитика спроса» открыт для аккаунта (личный кабинет → Аналитика) |

## 2. Установка

```powershell
cd <путь-к-клону>\product-research
npm run setup
```

Проверка работоспособности: `npm run check` (проверка синтаксиса).

## 3. Переменные окружения

Все переменные необязательны — сервер работает с настройками по умолчанию.
Задаются через PowerShell (`$env:AVITO_... = "..."`), системные переменные
или через секцию `env` в конфиге opencode (см. п. 5).

| Переменная | По умолчанию | Описание |
|---|---|---|
| `AVITO_DATA_DIR` | `%LOCALAPPDATA%\OpenCode\avito-analytics` | Локальный каталог данных (профиль, архив, состояние). По умолчанию он **не** находится в Synology Drive. |
| `AVITO_PROFILE_DIR` | `%AVITO_DATA_DIR%\profile` | Профиль браузера (там хранятся cookies авторизации) |
| `AVITO_CHANNEL` | авто: chrome → msedge → chromium | Какой браузер использовать |
| `AVITO_HEADLESS` | `false` | `true` — без окна (только если уже авторизованы) |
| `AVITO_MIN_INTERVAL_MS` | `8000` | Мин. пауза между запросами, мс |
| `AVITO_MAX_INTERVAL_MS` | `20000` | Макс. пауза между запросами, мс (интервал выбирается случайно) |
| `AVITO_MAX_REQUESTS` | `50` | Лимит запросов на серию |
| `AVITO_SESSION_COOLDOWN_MS` | `1800000` (30 мин) | Через сколько серия «сбрасывается» |
| `AVITO_BLOCK_COOLDOWN_MS` | `86400000` (24 ч) | Пауза при капче/блокировке |
| `AVITO_LOGIN_TIMEOUT_MS` | `300000` (5 мин) | Сколько ждать ручной авторизации |
| `AVITO_FETCH_TIMEOUT_MS` | `30000` | Таймаут одного запроса к Авито |

Не помещайте `AVITO_DATA_DIR` внутрь Synology Drive, Git-репозитория или общего сетевого каталога: там находятся cookies и состояние авторизованной сессии. Если ранее использовалось хранилище по умолчанию в `MCP\avito-analytics\data`, при закрытом MCP вручную перенесите только каталог `profile` в новый локальный каталог. Архивы ответов переносите лишь если они нужны для истории исследований.

Пример (PowerShell, до запуска opencode):

```powershell
$env:AVITO_MIN_INTERVAL_MS = "10000"
$env:AVITO_MAX_INTERVAL_MS = "25000"
$env:AVITO_MAX_REQUESTS = "30"
```

## 4. Первый запуск (авторизация)

Авторизация происходит один раз, дальше сессия переживает перезапуски:

1. Попросите ИИ вызвать инструмент `avito_session_open` (или сделайте это вручную из MCP-клиента).
2. Откроется окно браузера на `avito.ru/analytics` — войдите в аккаунт Авито.
3. Дождитесь появления страницы «Аналитика спроса» — сервер сам определит авторизацию.
4. Проверьте: `avito_session_status` → `authorized: true`.

Важно: пока сессия не авторизована, инструменты сбора данных (`avito_market`, `avito_wordstat`)
не вызываются — сначала `avito_session_open`.

## 5. Подключение к opencode

Возьмите готовый блок `avito-analytics` из `config/opencode.mcp.example.jsonc` в корне репозитория и замените `C:\path\to\product-research` на путь к своему клону. Эквивалентный блок для самостоятельного добавления в `opencode.json`:

```jsonc
{
  "mcp": {
    "avito-analytics": {
      "type": "local",
      "command": ["node", "C:\\path\\to\\product-research\\mcp\\avito-analytics\\server.mjs"],
      "cwd": "C:\\path\\to\\product-research\\mcp\\avito-analytics",
      "environment": {
        "AVITO_MIN_INTERVAL_MS": "8000",
        "AVITO_MAX_INTERVAL_MS": "20000"
      },
      "enabled": true
    }
  }
}
```

После этого перезапустите opencode.

## 6. Структура данных на диске

```
%LOCALAPPDATA%\OpenCode\avito-analytics\
├─ profile\              — профиль браузера + cookies (не удалять)
├─ archive\              — сырые ответы: ГГГГ-ММ-ДД\market-*.json, wordstat-*.json, location-*.json
├─ locations-cache.json   — кэш локаций
└─ state.json             — счётчик запросов, кулдауны, блокировки
```

Архив накапливается автоматически при каждом успешном ответе — это «сырьё» для дальнейшего анализа.

## 7. Безопасность и лимиты (важно)

- Сервер специально «тормозит»: паузы 8–20 сек и лимит 50 запросов на серию — это защита от бана аккаунта. Не отключайте и не уменьшайте без необходимости.
- При капче/403 сервер автоматически останавливает сбор на 24 ч (`blocked_until` в `avito_session_status`).
- Не запускайте два экземпляра сервера одновременно — конфликт за профиль браузера.
- Не удаляйте `profile` — иначе придётся заново проходить авторизацию.
- Для массового сбора желательно использовать отдельный аккаунт Авито, а не основной.
