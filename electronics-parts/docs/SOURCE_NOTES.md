# Исходные допущения

Архитектура опирается на текущий пользовательский `electronics-parts MCP`, который уже предоставляет:
- международные источники DigiKey/Mouser/LCSC/JLCPCB;
- российские/локальные источники;
- единый и параметрический поиск;
- наличие, MOQ, сроки и цены/price breaks для части источников;
- ограничение и безопасное поведение при 403/429/CAPTCHA.

OpenCode skills упакованы в `.opencode/skills/<skill>/SKILL.md` с frontmatter `name`/`description`, соответствуя текущей документации OpenCode Agent Skills.
